右上角那个主题按钮，在“跟随系统 / 浅色 / 深色”三个图标之间轮换。最早我是直接把图标换掉的，功能没问题，但点下去总觉得不太确定自己点到了没有。后来给它加了一点缩放和模糊，同一个按钮，手感就完全不一样了。

## 拆开看它怎么做到的

关键是**三个图标一直都在**，叠在按钮中心同一个位置，切换只改变哪一个“亮着”：

```css
.theme-icon {
  position: absolute;
  inset: 0;
  margin: auto;
  opacity: 0;
  filter: blur(4px);
  transform: scale(0.6);
  transition:
    opacity 0.25s ease,
    filter 0.25s ease,
    transform 0.25s ease;
}
[data-theme='dark'] .dark {
  opacity: 1;
  filter: blur(0);
  transform: scale(1);
}
```

- **缩放**是点击感的来源。图标先缩下去、新的再弹出来，跟手指按下、松开的节奏对得上，所以会让人觉得“这一下按到了”。
- **模糊**解决的是淡入淡出的重影。只改 `opacity` 的话，中间几帧太阳和月亮会半透明地叠在一起；加上 `blur(4px)`，两个轮廓被揉成一团，眼睛读到的是一次变化，而不是两个图形在换班。
- **时长**用 `0.25s ease`。界面动效基本都应该压在 300ms 以内，再慢就开始让人等了。
- 状态写在按钮的 `data-theme` 属性上，CSS 只负责“谁亮着”。所以 JS 里不用操心动画，只改一个属性。

本站的语言切换用的也是同一套参数（那边要跳页面，就把同样的退场动画放在跳转之前播完）。以后再有“在几个选项间轮换”的按钮，我都会直接套这一套，不再另起一种动画。

## 什么时候不该用

- 系统开启了减少动态效果，就去掉 `transition`，状态照样切换，只是不播动画。demo 里也是这样处理的。
- 图标之间如果本来就有很强的形变关系（比如汉堡菜单 → 关闭），用线条形变会比模糊更好，模糊是“没有更好的办法时”的通用解法。
- 只用在小图标、小标签上。一大块内容做模糊过渡，性能和观感都会变差。

## 出处

做法和参数来自本站 `Header.astro` 里的主题按钮，也写进了站点的 `DESIGN.md`（Blurred Icon Transition）。“缩放让按钮有回应”“没办法时就加一点模糊”这两条思路，Emil Kowalski 在 [_7 Practical Animation Tips_](https://emilkowal.ski/ui/7-practical-animation-tips) 里讲得很清楚，推荐一读。
