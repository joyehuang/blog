## 核心内容

Garry Tan 的长篇演讲（完整逐字稿深读）。这不是一篇「AI 很厉害」的鸡汤——它是一个 YC 掌门人把自己的个人 agent 架构（G Brain，Karpathy 风格知识 wiki，约 22 万 markdown 页、25 年生活日记化）完整公开的施工图，并用 17 世纪被逐出教门的斯宾诺莎做贯穿叙事。对他框架的折扣和政治含义的点评见文末。

## 核心论点：个人 AGI

用斯宾诺莎的异端做类比：「God or nature」——神不在王座上，弥散在万物中。400 年后的版本：**所有人都在等 AGI 作为单一事件降临（数据中心里的神），但它已经以基础设施的形态在房间里了**——一个终端窗口、一叠 markdown 文件、一个你睡觉时干完活的作业。

- **Personal AGI ≠ 订阅制 chatbot**：$20/月的 assistant 是「租的企业 AGI」——关掉标签页就重置、公司 pivot 时你的助手在别人的日程表上被切除脑叶
- **Personal AGI 的定义**：跑在你自己的基础设施上、读你拥有的记忆、执行你写的流程、**每天复利变好**的 agent。「一个是消费的产品，一个是积累的资产」
- **下一个十年的等式**：前沿模型（租的、商品化的、每季度降价）+ 你的 context（你独有，别人没有）+ harness（把它们接起来的运行时）= 一个行动起来像「快进版你」的 agent。**模型质量是租的，大脑是你自己的**

## 生产力数字（自我打折版）

2013 年他做 YC partner，每天有效产出 14 行代码（正好是程序员生产力文献的中位数）。2026 年同样的脑子、同样的时间外加接小孩，产出约 400 倍。他主动提供了最严苛的打折方式：假设 agent 代码臃肿、一半是脚手架、自我美化——**地板价仍是 8 倍**。YC W25 批次四分之一的公司代码库 95% AI 生成，这批是 YC 历史上增长最快的批次之一——「增长最快的创始人不把 AI 当 autocomplete，当 workforce 用」。

## 架构：库 + 图书管理员

- **工作记忆的物理学**：人类工作记忆 7±2（本店电话号码七位数的原因），人类文明的一切制度（清单、org chart、站会）都是这个限制的假肢。Agent 持有 1M tokens ≈ 1000 页——「三本哈利波特同时摊开在桌上」；但你的生活不是三本书，是**一座图书馆**
- **决定性问题**：「谁决定桌上摊开的是哪三本书？」——这就是 G Brain 的定位：图书馆 + 图书管理员
- **实例**：创始人来信谈危机，agent 在他读完邮件之前已经拉出与此人的全部历史往来、三家撞过同一堵墙的公司及实际有效的解法——「这是 assistant 和 colleague 的区别」
- **日常流**：睡觉时 agent 处理（不是分类，是处理）收件箱；每场会前自动生成 prep doc；半夜好奇的研究早上完成

## Markdown 即代码

- **Skill 文件「不魔法」**：一个真实的例子——「CircleBack 会议录音落地 → 带说话人标签转写 → 抽取承诺/负责人/deadline → 每个涉及的人与库中页面交叉链接 → 归档 → 与已有认知矛盾时标记而非覆盖」。就一页英文。**检验标准：一个聪明的实习生能照着做，agent 就能跑**
- 推论：「如果你能用英文写清楚指令，你就是程序员。编译器是语言模型」——YC 的媒体、财务、活动团队都在写 skill 文件；一位财务用内部 agent 把 100 个 Excel 编译成一个应用，「她不是程序员，她是 agent 的管理者，所有人都快是了」
- **两个计算空间**（他见过的每个 agent 失败都源于混淆这两者）：品味/判断/理解模糊请求属于 **latent space**，住在模型里，用 markdown 引导；算术/SQL/6000 人的会议排座属于 **deterministic space**，必须是 markdown 调用的代码和数据库。「模型在我们失败的地方失败，修法是让模型像人一样计算」

## 五步操作（演讲的 how-to 部分）

1. **今晚**：选一个 harness，在自己的机器上跑 agent——概念是重点，不绑定任何产品
2. **这周末**：起图书馆——不是一个宏大的档案，是一个 markdown 文件夹。每个项目、每个合作者写一页：在做什么、对方在意什么、你欠对方什么、上次说了什么。「这些信息地球上没有任何模型有，因为它们只在你脑子里——而你的脑子只装得下七件事」
3. **写第一个 skill 文件**：挑你每周最讨厌的任务，用「给聪明朋友讲第一天的工作」的方式讲给 agent，错了就纠正，「每条规则、每个例外、每个『哦还有』都写进去」——那页纸就成了一个员工
4. **接成定时任务**：第一次醒来发现活儿在睡觉时干完了，「那天起，『天』不再是你的工作单位，单位变成你能想象什么」
5. **纪律：永远不做一次性工作**——每个任务结束时让 agent 把做法 skillify 成可复用的 markdown。「**要两遍的东西就是你失败了**」：捕获学习的人每天变聪明，每天失忆的人在浪费模型进步

90 天曲线：第一周是玩具（修多于省）；第四周飞轮咬合（agent 用你的 context 回答，你写第三四个 skill）；第十二周图书馆在你问完前就开始回答。

## 三个反对的回应

- **「这不就是 RAG 吗」**：「Postgres 就是 B-tree」——检索是原语不是产品，难的是围绕它的一切：什么值得被写下来、怎么富化链接、什么进热记忆什么归冷档、**两个事实打架时谁仲裁**。「检索容易，值得被检索才是产品」
- **隐私**：「这正是它必须属于你的原因」——我的大脑跑在我自己的 infra、repo、key 上。对比默认状态：你的生活已经散落在十家动机与你相反的云里，「可被所有人搜索，除了你自己」。**我没制造风险，我接管了监护权（custody is the security model）**
- **为什么开源**：「强大的工具应该被送出去」——每个时代都有一种私有的杠杆技术（先是识字，然后是资本，现在是 harness + library + markdown 组成的 workforce）。私有 → 祭司阶层；开放 → 文艺复兴

## 我们的点评

**框架层面**：这是目前把「个人 agent + 记忆 + skills」讲得最完整的公开叙事，五步操作可以直接执行。和我们体系的对照：memory.md + mem0 ≈ 他的 library，recaps ≈ 时序索引，skills 仓库 ≈ 他的 skill files，herdr 常驻任务 ≈ 他的 recurring jobs——架构同构度极高，差别在他的库是 22 万页、我们的是「第一层书架」。他自己说得很对：「没人先建仓库，先建一个书架」。

**折扣层面**：400x 是叙事数字（他自己也给了 8x 地板价，诚实）；「个人 AGI」的边界在他自己的 caveat 里说得很清楚——**没人策展的大脑就是带搜索功能的垃圾场**，检索会以十足的自信翻出过期事实、坏 skill 文件把坏流程永久固化。这和我们从 PersonaMem-v3 学到的「过期偏好」失败模式完全一致：memory + hygiene（provenance、矛盾检查、负责修剪的图书管理员）才是完整原语。

**操作层面**：第 5 步的 skillify 纪律是最值得立刻抄的——「要两遍的东西就是你失败了」对应我们的 herdr-workflow 沉淀习惯，可以更激进：任何做过两遍的操作自动沉淀为 skill。
