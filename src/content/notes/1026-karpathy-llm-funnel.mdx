## 核心内容

2026 年 10 月 12 日，Andrej Karpathy 把 4 月 9 日那条帖子翻出来重发。当时他看到的是两群人在各说各话。半年后他改口：这道缝没有合上，而且在变宽。形状不再是两边对峙，而是一层层收窄的漏斗。

这篇按原帖的顺序往下记：

- 为什么不再是「两群人」
- 四层人群各自看到什么（人数是他的餐巾纸估算）
- 漏斗由哪三件事拉开
- 三件事叠在一起之后，为什么同一时刻会显得互相矛盾
- 做多 bot、cloud agent 的工作流，和仍停在聊天框的读者，分别落在哪一层

## 要点整理

### 1. 从两群人改成漏斗

4 月那条帖把第一件事放在使用的新旧和档位上。很多人在前一年试过免费版 ChatGPT，并让那一次体验过多地代表了自己对 AI 的看法。当时的收束是：这两群人在各说各话。

10 月重发时，他改的是形状。不再是两群人互相听不见，而是一个尖锐的漏斗：越往下人越少，看到的能力越极端。

### 2. 四层

**第 1 层**：约 60 亿人，大约总人口的 75%。几乎没接触过 LLM。

**第 2 层**：约 10 到 20 亿人，大约 20%。偶尔、也不频繁地用免费的类 ChatGPT 产品。看到的是一个傻乎乎的聊天机器人，用法接近更好的搜索，或者写作助手。偶尔会有一个 agent 试着去订机票。Karpathy 写到，他的一些非技术朋友说自己用不上，他觉得这个判断合理。数学和代码以外的很多专业人士也在这一层。高管是他举的例子：大量时间在跟人说话，对正在发生的事有理智上的了解，但仍然是二手的、偏抽象的。

**第 3 层**：约 2000 万人，0.2%。在数学和代码里专业使用前沿级 LLM。他们亲眼看到，过去要几周、几个月的大项目，现在一个 prompt 交给 agent 就能做完。他列的活包括做应用、抄应用、翻译应用、从二进制反编译应用。变化很近。不到一年前，他自己还在手写代码：把记熟的命令一个字一个字敲进编辑器，偶尔按一下 Tab 补一小段。

**第 4 层**：约 5000 人，大约 0.00006%。能在内部用到前沿系统。外面的人已经见过预告：成千上万个 agent 组成蜂群，协作几周做超大软件项目。他点到的包括挖零日、以机器速度做网络攻防、发现新科学、推进前沿数学。这些事以前要业内顶尖的人做上几年。与此同时，人的审查和理解开始跟不上。例子有两个。很多人还在对几个月前的 OpenAI-HF 事件做「考古」。数学家们可能还要埋头读一阵那 722 份前沿数学手稿。

### 3. 三件事在把漏斗拉开

**影响力随野心、问题规模和时间跨度放大**：一个答案只有一段话的问题，几乎压不到系统。手里要有一池子自己真正在乎、又大又难的问题，差别才感觉得到。这一维分开的是消费者和专业人士。

**能力是锯齿状的**：峰在数字化、可验证、经济价值高的领域。LLM 的能力来自在可验证奖励上做强化学习，训练环境的配比又按营收潜力来挑。这一维分开的是领域。数学和代码在峰上；领域不在峰上，看到的提升就小。

**访问分三档**：免费版、付费版、内部版。三档看到的不是同一个东西。

**三件事叠在一起**：没有大问题的人看不到上限；有大问题但不在数学和代码里的人，碰到的是锯齿的低谷；真正在峰顶的那一档，大多数人用不到。

### 4. 同一时刻为什么会互相矛盾

公众大多没跟这些系统打过交道。打过交道的，看到的是傻乎乎的聊天机器人。多数专业人士感受到的只是温和的提升。只有一小撮专业人士在经历曲线变垂直的眩晕。

**这些全都同时发生。** 「AI 没什么用」和「曲线已经垂直」可以同时为真，因为它们说的不是同一层。

### 5. 做事的人和读者落在不同层

按第一个驱动因素，能看见曲线变陡，手里要有自己在乎的大问题。正在搭多 bot、让 cloud agent 持续干活的工作流，通常已经靠近第 3 层：问题在代码里，规模也够得上「几周的项目交给一个 prompt」。这一层仍然不是内部那约 5000 人。蜂群协作几周、人的审查开始跟不上，要的是另一档访问。

很多读者还在第 2 层：用过免费版，AI 就是一个聊天框。对着这一层先讲 bot 团队或 cloud agent，词会先到，经验不到。能跨一小步的，是一个已经离开聊天框的具体例子，而不是先讲架构。比如[《Personal Agent 拆解：模型越强，产品越要做减法》](/blog/20261011---alwaysonagents/post)里那个场景：跟主 bot 说想要几个新伙伴，它自己去招人、拉群、做 onboarding，然后各自开 cloud agent 干活。
