## 核心内容

智谱（GLM 团队）唐杰的长文，主题一句话：**模型能力不只看参数量，「缩放」有四个独立旋钮，该拧哪个是门学问**。GLM-5.3 是他的验证实验——和 GLM-5.2 同基座、同架构、同参数量，唯一区别是一个月长视野环境 + RL 后训练，收益却不是边际的。

## 缩放定律的演进史

- **Kaplan 2020**：参数要比数据涨得快（2.7:1）——催生了 GPT-3 / Gopher / MT-NLG 那批超大模型
- **Chinchilla 2022**（Hoffmann）：重新实验 400 个模型，发现最优约 20 token/参数，参数和数据应该同步涨——上一代万亿参数模型是「整个领域一起走的弯路」
- **推理时代**：模型每天被调用几十亿次，推理成本主导生命周期。把推理计入优化目标后，最优解变成**小模型 + 训练更久**——Llama-2-7B 约 290 token/参数，Gemma-2-9B 约 889

## MoE 打破单一缩放

文章的重点：MoE 架构下「参数量」分裂成两个独立的东西——

- **总参数量** ≈ 模型「知道多少」（知识、事实、长尾）
- **激活参数 / 有效深度** ≈ 模型「能想多深」（能推多少步因果链）

两者不是一回事。固定 token-per-parameter 时，**总参数量堆高反而损害推理**；激活更多 expert 才真正提升推理能力。

## 安全领域的映射（作者的核心论点）

> 「发现漏洞不是检索问题——不是记住更多 CVE，而是能连续推理二十步不丢失线索。这个能力不在总参数量里。」

这句是全文对 agent 从业者最有引用价值的一句：它直接解释了为什么「检索到相关知识」和「解决安全问题」是两回事——后者考验的是有效深度，不是知识存量。也解释了为什么同一个底座模型，换个 harness 能差出一大截。

## GLM-5.3：只拧一个旋钮的验证实验

- 与 GLM-5.2 同基座、同架构、同参数量，唯一变量：**一个月长视野环境 + RL 后训练**
- 收益不是边际的——证明**后训练（post-training）这个旋钮还有大量 slack**，值得单独拧
- 作者的克制之处：不是宣称其他旋钮到头了（预训练、数据、前向计算都还在桌上），而是**每次值得先拧的旋钮不同**

## 评论区的延伸

- MoE 的唯一路径数超过训练 token 总数——路径组合空间大得离谱，这从组合数学角度支持「激活模式比参数量更能刻画能力」
- 参数量越来越不适合当能力简写：同架构同大小，一个月更好的环境 + RL 就能拉开巨大差距

## 我们的对照

- 验证了「后训练/RL 是当前瓶颈」的判断：GLM-5.3 只转一个旋钮就有大收益——对应到 agent 场景，harness 侧的「环境 + RL」类比就是「更好的工作流 + 更多真实任务的反馈循环」
- 小模型 + 超长训练的性价比路线，正是日常任务用 flash 档模型、把重活留给强模型的路由策略的理论依据
- 「总参数 vs 有效深度」的区分对我们选模型也有操作意义：知识型任务（长尾事实多）看总参数，推理型任务（多步因果链）看激活/有效深度——flash 档小模型在后者上的差距比前者小

## 当前理解 / 结论

- 「缩放」从一个旋钮（参数）变成了四旋钮（参数、数据、前向计算、后训练），模型评测和选型的语言还没跟上——按参数量分档正在失去解释力
- 对 agent 工程的启示：与其等更大底模，不如把赌注押在「环境质量 + RL 后训练」上——这是 harness/工作流层从业者能施加影响的两个旋钮
- 唯一变量实验（同基座只拧后训练）是难得的干净证据，比「新模型全面更强」的发布话术有信息量得多
